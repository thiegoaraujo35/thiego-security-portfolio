# Thiego Araújo — Cybersecurity Portfolio

Responsive personal portfolio designed for GitHub Pages.

## Files

- `index.html` — structure/content
- `style.css` — visual design and responsive layout
- `script.js` — menu, filters and dynamic year

## Publish on GitHub Pages

1. Create a public repository, e.g. `thiego-security-portfolio`.
2. Upload the three files to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

## Customize before publishing

Search and replace:

- `https://www.linkedin.com/` with your LinkedIn URL
- `https://github.com/` with your GitHub URL
- `your@email.com` with your professional email
- Sample certification names with your real certificates
- `VERIFY ↗` links with official certificate verification URLs
- Project links with your real repositories

Do not publish certificates containing CPF, address, document numbers or other unnecessary personal information.
