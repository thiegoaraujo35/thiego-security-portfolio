Anexar certificados e documentos

Escolha os arquivos, preencha o que quiser e clique em Gerar pacote. Nada sai do seu computador até você publicar.

1. AnexeArraste os PDFs/imagens aqui embaixo (o nome do arquivo com o código, ex.: AZ-104.pdf, já associa sozinho).
2. Gere o pacoteO botão no fim da página baixa um .zip com os arquivos e o uploads.js atualizado.
3. PubliqueExtraia o zip e arraste a pasta assets para o repositório no GitHub (Add file → Upload files).
Atenção: tudo que você anexar fica público no site. Certificados e transcripts costumam ter dados pessoais (CPF, RG, matrícula, endereço, nº de candidato, e-mail). Antes de anexar, apague ou cubra esses dados no PDF, ou use só o link de verificação (Credly, Microsoft Learn “Share transcript”, etc.) no campo de link, sem anexar o arquivo. Histórico escolar completo: prefira não publicar.
